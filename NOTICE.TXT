Prominent notice of modification (GPL-3.0 section 5a)
-----------------------------------------------------
Flobo Display is a fork: the source code has been modified with respect to
EEZ Studio. Principal modifications:

    1. Rebranding of the product name from "EEZ Studio" to "Flobo Display"
       (window titles, menus, dialogs, file dialog filters, About box,
       HTML titles, installer metadata, package metadata and documentation).
    2. Application identity: productName is now "Flobo Display" and the
       application id is "com.flobo.display"; the npm package name is
       "flobo-display".
    3. About box links and the update check point to the Flobo Display
       repository (https://github.com/cristianflobo/flobo-display).
    4. Docker based LVGL simulator: image and volume names renamed to
       "flobo-display-lvgl-build".
    5. UI font families renamed to "Flobo Display Font" and
       "Flobo Display Font Monospace".
    6. Nix derivation and flake attribute renamed from "eez-studio" to
       "flobo-display".

Intentionally NOT renamed (compatibility and attribution)
---------------------------------------------------------
    - The GPL-3.0 license text (LICENSE.TXT) and the third-party license
      notices (THIRD-PARTY-LICENSES.TXT).
    - Project/file extensions (.eez-*) and their MIME types
      (application/x-eez-*), so that existing projects remain compatible.
    - Frameworks, engines and their public API: "EEZ Flow", "EEZ GUI" and
      "EEZ GUI Lite" (eez-flow.h/.c/.cpp, eez-gui-lite.h/.c, EEZ_FLOW_* and
      EEZ_GUI_LITE_* macros, project type names such as "LVGL with EEZ Flow").
    - Internal package/folder names and import specifiers (eez-studio-shared,
      eez-studio-ui, eez-studio-types, ...).
    - Upstream attributions and links: Envox d.o.o., the EEZ Studio
      documentation, the extensions catalog and third-party components
      (LVGL, lv_font_conv, pdf.js, etc.).
